scrollring

A tiny, framework-agnostic virtual list that recycles a fixed set of DOM nodes. Scroll through 100,000 rows and watch the node count stay the same.

A fixed pool

Only the rows near the viewport get a node. The pool size depends on the viewport height, not on how many rows the list has.

Ring assignment

Row i always goes to node i % poolSize, so a small scroll only repaints the rows that came into view.

Grows on resize

Switch to 800px: a ResizeObserver adds nodes so the taller viewport stays filled.
